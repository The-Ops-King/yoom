# Phase 2.1: Recorder feedback patch — Implementation Plan

**Status:** in progress on branch `phase2.1-feedback`.

**Goal:** Fix seven pieces of feedback from Tyler's first real run of the Phase 2
recorder: kill the native HTML5 drag ghost, drop camera-bubble virtual
backgrounds entirely (framed-capture backgrounds stay), allow switching modes
after setup, add an immediate Restart and a Cancel (trash) control, animate
bubble transitions in the compositor, and refresh the docs.

**Architecture is unchanged:** `recorder-machine.ts` stays a pure reducer with a
test for every event, `compositor.ts` stays React-free, `use-recorder.ts` is the
only bridge between them, and `media-sources.ts` remains the only caller of
`navigator.mediaDevices`.

## Items

1. Kill the native drag ghost on the bubble handle.
2. Remove camera-bubble backgrounds + MediaPipe segmentation entirely.
3. Allow switching modes (and surface pref) while in `setup`.
4. Restart-without-countdown + Cancel (discard and return to setup).
5. Animated bubble transitions in the compositor.
6. Docs + verification.

### Task 1 — Kill the native drag ghost

- `bubble-drag-overlay.tsx`: handle stays a `<div role="slider">`; add
  `draggable={false}`, `onDragStart` preventing default, `select-none touch-none`,
  and `e.preventDefault()` in `onPointerDown` before `setPointerCapture`.
- `preview-stage.tsx`: `draggable={false}` on the canvas and the `<video>`,
  `onDragStart={(e) => e.preventDefault()}` + `select-none touch-none` on the
  stage wrapper.
- Verified by reading; not unit-testable.

### Task 2 — Remove camera-bubble backgrounds

- Delete `background-picker.tsx`, `segmentation.ts`, `scripts/copy-mediapipe.mjs`,
  `public/models/selfie_segmenter.tflite`; `npm rm @mediapipe/tasks-vision`; drop
  `predev`/`prebuild`, the `public/mediapipe` gitignore line and eslint ignore.
- `compositor.ts`: `CompositorSources.maskCanvas`, `setBackground`, `personCanvas`,
  `personScratch` and the whole background plate go; `drawCameraLayer` becomes
  mirror → draw camera crop. `drawFrameBackground` and `FrameConfig.background` stay.
- Reducer/settings/hook: remove `background` state, `SET_BACKGROUND`, `setBackground`.
  `loadSettings` ignores an unknown `background` key; storage key → `yoom.recorder.v2`.
- `presets.ts`: keep `FRAME_PRESETS` + `COLOR_SWATCHES` (frame picker uses both);
  fold the catalogue into `FRAME_PRESETS` and delete `BACKGROUND_PRESETS`/`findPreset`
  and their tests.
- Update `README.md` and add a line to `docs/for-later.md`.

### Task 3 — Switch modes after setup

- `ModePicker` `disabled` becomes `status !== "idle" && status !== "setup"`.
- Hook `switchMode(mode)`: from `setup` → `teardown()`, `STREAM_ENDED`, `SELECT_MODE`,
  then `acquire()` on the next tick; from `idle` → plain `SELECT_MODE`.
- Same teardown+reacquire path for `setSurfacePref` while in `setup`.
- Reducer test: `setup → STREAM_ENDED → SELECT_MODE(camera)` ⇒ idle / camera / no streams.

### Task 4 — Restart-now + Cancel

- Reducer: `RESTART_NOW` (countdown/recording/paused → recording, `elapsedMs: 0`,
  `blob: null`) and `CANCEL` (countdown/recording/paused/stopping → setup, cleared).
  Tests per source state and no-ops elsewhere. `RESTART` stays.
- Hook: `restartNow()` stops+discards the MediaRecorder, nulls `recorderRef`, bumps a
  `restartTokenRef` the begin-recording effect depends on; `cancel()` stops the
  recorder with `onstop = null`, clears chunks/thumbnail/timers, dispatches `CANCEL`.
- Hotkeys: ⌘⇧K restart-now, ⌘⇧X cancel (⌘⇧L, ⌘⇧P unchanged).
- UI: Pause/Resume, Stop, Restart (↻), Cancel (trash, red-tinted, `aria-label="Cancel recording"`).

### Task 5 — Animated bubble transitions

- `geometry.ts`: `easeInOutCubic(t)`, `lerpRect(a, b, t)`, `shapeRadius(shape, w, h)`
  (circle `min/2`, rounded/portrait `0.08*min`, square `0.04*min`, full `0`) + tests.
- `compositor.ts`: `fromRect`/`toRect`/`animStartMs`, 300 ms ease-in-out, per-frame
  `Path2D` from the interpolated rect and radius, per-frame `coverCrop` on the
  interpolated aspect, scale-to-zero on `visible: false`, snap on the first draw.
- `setBubble(cfg, { immediate })`: pos-only changes (drag) snap; the drag overlay
  passes `immediate` and the hook forwards it to the compositor while still
  dispatching `SET_BUBBLE`.

### Task 6 — Docs + verification

- README hotkeys/Cancel/Restart/animated bubble, backgrounds removed.
- `docs/for-later.md`: "Phase 4 requirements from Phase 2 testing" with the
  floating always-on-top camera bubble window.
- `npm test`, `npm run build`, `npm run lint`; report counts.
